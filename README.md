# Tranquil Tips

**Rotating tips shown in [Tranquil Studio](https://github.com/tranquillabs/tranquil-client) when no editor is open.**

> Part of the Tranquil toolkit, in early developer preview.

## What it does

- Shows a rotating tip — with rendered keybinding badges — in the empty editor background.
- Cycle to the next tip with a command.
